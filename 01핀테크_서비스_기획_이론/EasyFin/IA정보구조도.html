EasyFin V2.0 정보구조(IA)

모바일 하이브리드 금융 정보 플랫폼 · V2.0 MVP 프로토타입 기준

1. IA 개요

본 문서는 EasyFin V2.0 서비스의 화면 구조와 메뉴 계층, 주요 사용자 플로우를 정의한 정보구조(IA) 문서이다. 현재 버전은 실제 구현된 V2.0 MVP 프로토타입(로그인/회원가입, 홈/마켓/라이브/커뮤니티/마이)을 기준으로 작성되었으며, 향후 확장 예정 기능은 별도 표기하였다.

  • 대상 플랫폼: 모바일 앱 (React Native + Expo) · 웹 프로토타입은 React + FastAPI 백엔드 구조 참고
  • 주 사용자: 일반 개인 투자자(초보~중급), 금융 콘텐츠 크리에이터(전문가)
  • 주요 기능: 자산 요약 조회, 금융상품 탐색(마켓), 라이브 목록 확인, 커뮤니티 글 작성, 마이 페이지 관리

2. 주요 사용자 타입

사용자 타입 설명 핵심 목적
일반 투자자 투자 경험이 많지 않고, 공모주/ETF/채권/리츠 등 정보를 쉽게 알고 싶은 사용자 내 자산 현황 파악, 이해하기 쉬운 콘텐츠/라이브 확인, 커뮤니티에서 질문/소통
경험자/고급 투자자 여러 금융상품을 이미 운용 중이며, 정보 비교/분석에 관심이 높은 사용자 상품 리스트/기본 정보 확인, 위험도 레벨 확인, 관심 있는 라이브/게시글 탐색
전문가/크리에이터 (향후) 라이브 방송 및 콘텐츠를 제공하는 금융 전문가, 크리에이터 라이브 운영, 구독자/시청자 관리, 콘텐츠 성과 확인 (현재 프로토타입에서는 뷰어 플로우만 구현)
운영자(Admin) (향후) 내부 운영 담당자, 콘텐츠/이벤트/공지/사용자 신고 관리 콘텐츠 품질 유지, 신고 처리, 지표 모니터링 (별도 어드민 웹으로 분리 계획)

3. 글로벌 네비게이션 구조

3.1 하단 탭바(메인 NAV)

모바일 앱 기준, 하단에 고정되는 탭바 구조이다. V2.0 프로토타입에서도 동일한 탭 구조를 사용한다.

탭 이름 아이콘(예시) 역할
홈 🏠 요약 대시보드(총 자산·자산 비중 리스트·계좌 요약), 추천 라이브 진입점 제공
마켓 📈 공모주, ETF, 채권, 리츠 등 금융상품 탐색/검색, 상품 상세 모달 제공
라이브 📺 진행중/예정/다시보기 라이브 목록 확인 (시청 화면 및 채팅은 향후)
커뮤니티 💬 간단 게시글 작성 및 목록 조회 (댓글/고급 기능은 향후)
마이 👤 내 프로필, 팔로우 중 전문가, 연동 금융사 목록, 로그아웃 등 계정 관련 기능

3.2 상단 공통 App Bar

  • 좌측: 현재 탭명(예: 홈, 마켓, 라이브, 커뮤니티, 마이)
  • 우측: 검색 아이콘, 알림 아이콘 (프로토타입에서는 아이콘만 표시, 동작은 추후 구현)
  • 상세 화면/모달: 필요 시 뒤로 가기 버튼(←) 또는 닫기(✕) 버튼 제공
