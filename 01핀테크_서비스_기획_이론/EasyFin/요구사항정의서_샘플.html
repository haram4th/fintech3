EasyFin V2.0 요구사항 정의서 (최종)

본 문서는 EasyFin V2.0 서비스 IA 및 실제 프로토타입(로그인/회원가입, 홈/마켓/라이브/커뮤니티/마이) 기준으로 작성된 요구사항 정의서이다.

1. 문서 목적

본 요구사항 정의서는 EasyFin V2.0 서비스의 기능 정의, 화면 정의, 사용자 흐름, 비기능 요구사항을 명확히 기술하여 개발·디자인·기획 단계에서 일관된 기준을 제공하기 위함이다.

2. 서비스 개요

  • 서비스명: EasyFin V2.0
  • 목적: 개인 투자자를 위한 금융정보 탐색·자산 관리·커뮤니티·라이브 기반 금융 서비스
  • 플랫폼: 모바일 앱(React Native) / 프로토타입(React Web)
  • 핵심 제공 가치: “내 자산을 한눈에, 금융정보를 쉽게, 콘텐츠 기반 탐색”

3. 사용자 정의

사용자 그룹설명핵심 니즈
초보 투자자 금융지식이 적고 쉬운 설명과 요약된 정보를 원하는 사용자 내 자산의 간단 요약, 기본 용어, 쉬운 상품 설명
중급 투자자 여러 금융상품을 운용하며 정보를 빠르게 비교/탐색 상품 리스트, 간단 수익률/위험도 확인
금융 전문가(향후) 라이브 방송/게시글 제공자 라이브/콘텐츠 업로드 및 관리 기능

4. 전체 시스템 구성

4.1 주요 구성 요소

  • 프론트엔드: React (웹 프로토타입), React Native(앱 전환 예정)
  • 백엔드: FastAPI 기반 REST API
  • DB: PostgreSQL
  • 외부 연동(향후): 금융사 계좌 인증 API, 알림 서버 등

5. 정보구조(IA)

EasyFin V2.0의 최신 정보구조는 아래와 같다. (프로토타입 구조 기준)

    • CM-001: 게시글 목록
    • CM-002: 게시글 작성

    • MY-001: 마이 메인

6. 기능 요구사항(FR)

6.1 온보딩/가입

ID요구사항설명
FR-001 온보딩 화면 제공 서비스 소개 문구와 EasyFin V2.0 로고 보여줌
FR-002 로그인/회원가입 이메일·비밀번호 기반 로그인/회원가입(탭 방식)
FR-003 약관 동의 회원가입 시 필수 약관 체크

6.2 홈(대시보드)

ID요구사항설명
FR-010 총 자산 표시 금액 숫자 + KRW로 표시
FR-011 자산 비중 표시 예금/주식/ETF/채권/현금 등 항목별 금액 표시
FR-012 계좌 요약 표시 금융사/상품명/계좌 잔액 정보 노출
FR-013 추천 라이브 섹션 표시 라이브 탭으로 이동하는 링크 제공

6.3 마켓

ID요구사항설명
FR-020 상품 카테고리 탭 공모주 / ETF / 채권 / 리츠 탭 구성
FR-021 상품 리스트 제공 상품명, 코드, 위험도, 예상 수익률 표시
FR-022 상품 상세 모달 상품 클릭 시 상세 정보 모달 팝업

6.4 라이브

ID요구사항설명
FR-030 라이브 목록 제공 진행중 / 예정 / 다시보기 탭 방식
FR-031 라이브 상세(향후) 영상 플레이어 + 채팅 + Q&A

6.5 커뮤니티

ID요구사항설명
FR-040 게시글 목록 제목/작성자/시간/내용 일부
FR-041 게시글 작성 제목 + 내용 작성 및 등록
FR-042 게시글 상세(간단) 리스트 내 본문 펼침 정도 수준

6.6 마이

ID요구사항설명
FR-050 프로필 조회 닉네임/이메일 표시
FR-051 연동된 금융사 조회 향후 자산 연동 API와 연계
FR-052 팔로우 전문가 조회 더미 데이터 기반
FR-053 로그아웃 세션 초기화 후 로그인 화면 이동

7. 화면 요구사항(UI)

화면 ID화면명설명
UI-001 온보딩 화면 서비스 소개 문구 및 앱 시작 버튼 제공
UI-002 로그인/회원가입 화면 이메일/비밀번호 입력, 회원가입/로그인 탭
UI-003 대시보드 화면 총 자산, 자산 비중 리스트, 계좌 카드, 추천 라이브
UI-004 마켓 화면 카테고리 탭, 상품 리스트, 상품 상세 모달
UI-005 라이브 화면 라이브 목록 탭 구조 (재생 화면은 향후)
UI-006 커뮤니티 화면 게시글 작성/목록/간단 상세 UI
UI-007 마이 화면 프로필, 연동 금융사, 전문가 목록, 로그아웃

8. 비기능 요구사항(NFR)

8.1 성능

  • 홈/마켓/라이브/커뮤니티 화면은 1초 이내 렌더링

8.2 보안

  • 비밀번호는 백엔드에서 암호화 저장
  • 회원 인증 후 API 호출은 JWT 기반으로 진행(향후)

8.3 확장성

  • 상품 데이터, 라이브 목록은 API 확장 가능한 구조
  • 마켓 상세 정보는 차트·콘텐츠 연계 기능 추가 가능
