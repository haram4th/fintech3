Finuts V2.0 정보구조(IA)

모바일 하이브리드 금융 정보 플랫폼 · V2.0 MVP 프로토타입 기준

1. IA 개요

본 문서는 Finuts V2.0 서비스의 화면 구조와 메뉴 계층, 주요 사용자 플로우를 정의한 정보구조(IA) 문서이다. 현재 버전은 실제 구현된 V2.0 MVP 프로토타입(로그인/회원가입, 홈/마켓/라이브/커뮤니티/마이)을 기준으로 작성되었으며, 향후 확장 예정 기능은 별도 표기하였다.

  • 대상 플랫폼: 모바일 앱 (React Native + Expo) · 웹 프로토타입은 React + FastAPI 백엔드 구조 참고
  • 주 사용자: 일반 개인 투자자(초보~중급), 금융 콘텐츠 크리에이터(전문가)
  • 주요 기능: 자산 요약 조회, 금융상품 탐색(마켓), 라이브 목록 확인, 커뮤니티 글 작성, 마이 페이지 관리

2. 주요 사용자 타입

사용자 타입 설명 핵심 목적
일반 투자자 투자 경험이 많지 않고, 공모주/ETF/채권/리츠 등 정보를 쉽게 알고 싶은 사용자 내 자산 현황 파악, 이해하기 쉬운 콘텐츠/라이브 확인, 커뮤니티에서 질문/소통
경험자/고급 투자자 여러 금융상품을 이미 운용 중이며, 정보 비교/분석에 관심이 높은 사용자 상품 리스트/기본 정보 확인, 위험도 레벨 확인, 관심 있는 라이브/게시글 탐색
전문가/크리에이터 (향후) 라이브 방송 및 콘텐츠를 제공하는 금융 전문가, 크리에이터 라이브 운영, 구독자/시청자 관리, 콘텐츠 성과 확인 (현재 프로토타입에서는 뷰어 플로우만 구현)
운영자(Admin) (향후) 내부 운영 담당자, 콘텐츠/이벤트/공지/사용자 신고 관리 콘텐츠 품질 유지, 신고 처리, 지표 모니터링 (별도 어드민 웹으로 분리 계획)

3. 글로벌 네비게이션 구조

3.1 하단 탭바(메인 NAV)

모바일 앱 기준, 하단에 고정되는 탭바 구조이다. V2.0 프로토타입에서도 동일한 탭 구조를 사용한다.

탭 이름 아이콘(예시) 역할
홈 🏠 요약 대시보드(총 자산·자산 비중 리스트·계좌 요약), 추천 라이브 진입점 제공
마켓 📈 공모주, ETF, 채권, 리츠 등 금융상품 탐색/검색, 상품 상세 모달 제공
라이브 📺 진행중/예정/다시보기 라이브 목록 확인 (시청 화면 및 채팅은 향후)
커뮤니티 💬 간단 게시글 작성 및 목록 조회 (댓글/고급 기능은 향후)
마이 👤 내 프로필, 팔로우 중 전문가, 연동 금융사 목록, 로그아웃 등 계정 관련 기능

3.2 상단 공통 App Bar

  • 좌측: 현재 탭명(예: 홈, 마켓, 라이브, 커뮤니티, 마이)
  • 우측: 검색 아이콘, 알림 아이콘 (프로토타입에서는 아이콘만 표시, 동작은 추후 구현)
  • 상세 화면/모달: 필요 시 뒤로 가기 버튼(←) 또는 닫기(✕) 버튼 제공

4.2 온보딩/가입 IA

화면 ID 화면명 상위 메뉴 설명 (MVP 기준)
ON-001 간단 온보딩 소개 온보딩/가입 로고("Finuts V2.0")와 한 줄 설명 카피로 서비스 가치를 간단히 소개
ON-002 로그인/회원가입 온보딩/가입 이메일·비밀번호 기반 로그인/회원가입 탭 제공, 데모 계정 안내 포함 (SNS 로그인은 향후)
ON-003 약관 동의 온보딩/가입 회원가입 폼 내 필수 약관 동의 체크박스 제공 (상세 약관 화면은 향후)
ON-004 초기 가이드/간단 설문 (향후) 온보딩/가입 투자 경험, 관심 상품 카테고리 등을 입력 받아 초기 추천 피드 구성 (현재 프로토타입에는 포함되지 않음)

4.3 홈/대시보드 IA

화면 ID 화면명 상위 메뉴 설명 (MVP 기준)
HM-001 홈 대시보드 홈 총 자산(금액)과 예금/주식/ETF/채권/현금 비중을 텍스트 리스트로 제공, 계좌별 요약 카드 및 추천 라이브 영역 포함
HM-002 자산 카드 상세 (향후) 홈 계좌별 상세 정보, 최근 거래 내역, 관련 콘텐츠 추천 화면 (현재는 요약 카드까지만 구현)
HM-003 퀵 액션 시트 (향후) 홈 자산 연동, 관심상품 추가, 알림 설정 등을 빠르게 접근하는 하단 시트 UI (MVP 범위 밖)

4.4 마켓 IA

화면 ID 화면명 상위 메뉴 설명 (MVP 기준)
MK-001 마켓 메인 마켓 상단 카테고리 탭(공모주/ETF/채권/리츠), 선택된 카테고리의 상품 리스트를 한 화면에서 제공
MK-002 상품 리스트 마켓 카테고리 선택/검색 조건에 따른 상품 목록. 코드, 상품명, 발행사, 예상 수익률, 위험도 요약 표시
MK-003 상품 상세 모달 마켓 모달 형태로 기본 정보(코드/이름/발행사), 예상 수익률, 위험도 레벨을 보여줌. 차트·관련 라이브/커뮤니티 연결은 향후 추가

4.5 라이브 IA

화면 ID 화면명 상위 메뉴 설명 (MVP 기준)
LV-001 라이브 메인 라이브 진행중 / 예정 / 다시보기 탭으로 구분된 라이브 목록. 제목, 진행자, 시간, 상태 배지 표시
LV-002 라이브 시청 화면 (향후) 라이브 영상 플레이어, 채팅, Q&A, 좋아요/팔로우 기능 포함한 시청 전용 화면 (현재 프로토타입에는 포함되지 않음)
LV-003 라이브 일정 캘린더(선택 · 향후) 라이브 날짜별 예정 라이브 확인, 알림 설정 화면 (MVP 범위 밖)

4.6 커뮤니티 IA

화면 ID 화면명 상위 메뉴 설명 (MVP 기준)
CM-001 커뮤니티 메인 커뮤니티 기본 게시판(예: 자유/질문 등) 선택, 새 글 작성 폼과 최근 게시글 목록을 한 화면에서 제공
CM-002 게시글 목록 커뮤니티 제목, 작성자, 작성 시간, 간단 내용이 보이는 리스트. 간단 필터/정렬은 향후
CM-003 게시글 상세 (간단) 커뮤니티 목록 내에서 본문을 함께 표시하는 간단 상세 뷰. 별도 상세 페이지 및 댓글 리스트는 향후 확장
CM-004 글 작성/수정 커뮤니티 텍스트 기반 글 작성 가능. 이미지 첨부·수정/삭제 기능은 단계적으로 확장 예정

4.7 마이 영역 IA

화면 ID 화면명 상위 메뉴 설명 (MVP 기준)
MY-001 마이 메인 마이 닉네임·이메일 등의 기본 프로필, 팔로우 중인 전문가, 연동된 금융사 목록, 로그아웃 버튼 제공
MY-002 자산 연동 관리 (향후) 마이 연동된 금융사/계좌 목록, 해지/재연동 기능 화면. 현재는 리스트만 마이 메인에서 노출
MY-003 관심 상품/저장 콘텐츠 (향후) 마이 즐겨찾기한 상품/라이브/게시글 리스트 화면 (MVP 범위 밖)
MY-004 알림 설정 (향후) 마이 라이브 알림, 상품 알림, 마케팅 수신 여부 설정 화면 (현재 미구현)
MY-005 보안/인증 설정 (향후) 마이 PIN/바이오인증, 자동 잠금 시간, 기기 관리 화면 (현재 미구현)
MY-006 고객센터/문의 (향후) 마이 FAQ, 1:1 문의, 약관/정책 보기 화면 (현재 미구현)

5. 주요 사용자 플로우 요약

5.1 가입 & 첫 접속 플로우 (MVP)

  1. ON-001 간단 온보딩 소개 (로고 + 한 줄 설명)
  2. ON-002 로그인/회원가입 화면 진입
  3. ON-003 약관 동의 체크
  4. HM-001 홈 대시보드 진입 · 더미 자산 데이터 및 계좌 요약 확인

5.2 마켓 탐색 플로우 (MVP)

  1. 하단 탭바에서 ‘마켓’ 탭 선택 (MK-001)
  2. 카테고리 탭(공모주/ETF/채권/리츠) 중 하나 선택
  3. 선택된 카테고리의 상품 리스트(MK-002) 확인
  4. 상품 클릭 → 상품 상세 모달(MK-003)에서 기본 정보·위험도·예상 수익률 확인

5.3 라이브 목록 확인 플로우 (MVP)

  1. 하단 탭바에서 ‘라이브’ 탭 선택 (LV-001)
  2. 진행중/예정/다시보기 탭 전환으로 라이브 목록 탐색
  3. (향후) 라이브 아이템 클릭 → 라이브 시청 화면(LV-002)에서 재생 및 Q&A 참여

5.4 커뮤니티 글 작성 플로우 (MVP)

  1. 하단 탭바에서 ‘커뮤니티’ 탭 선택 (CM-001)
  2. 게시판 선택 후 글쓰기 폼에 제목/내용 입력 (CM-004)
  3. 작성 완료 시 게시글 목록(CM-002)에 최신 글로 반영

5.5 마이 프로필 & 로그아웃 플로우 (MVP)

  1. 하단 탭바에서 ‘마이’ 탭 선택 (MY-001)
  2. 프로필 정보(닉네임/이메일), 팔로우 전문가, 연동 금융사 목록 확인
  3. ‘로그아웃’ 버튼 클릭 → 사용자 세션 초기화 후 ON-002 로그인/회원가입 화면으로 이동
